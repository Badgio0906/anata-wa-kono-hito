# あなたはこの人を知っていますか？

[Web版をプレイ](https://badgio0906.github.io/anata-wa-kono-hito/)

スマートフォンでは横向きにして遊んでください。PCではマウス、Enter・Space、方向キーで操作できます。WebGL 2対応ブラウザが必要です。初回の読み込みには時間がかかる場合があります。

進行状況は使用中のブラウザ内に保存されます。ブラウザのサイトデータを削除するとセーブも消えます。

既周回数は「設定・操作」→「デバッグ項目」で確認・増減できます。変更はすぐ保存され、次のプレイの周回数と周回に応じた展開に反映されます。

このリポジトリにはGodot 4.5.1で出力したWeb版のみを置いています。
