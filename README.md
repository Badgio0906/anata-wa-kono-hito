# あなたはこの人を知っていますか？

[Web版をプレイ](https://badgio0906.github.io/anata-wa-kono-hito/)

スマートフォンでは横向きにして遊んでください。PCではマウス、Enter・Space、方向キーで操作できます。WebGL 2対応ブラウザが必要です。初回の読み込みには時間がかかる場合があります。

プレイ中の上部「回答」から、今周回で写真の質問に選んだ答えを人物ごとに見返せます。

進行状況は使用中のブラウザ内に保存されます。ブラウザのサイトデータを削除するとセーブも消えます。

既周回数は「設定・操作」→「デバッグ項目」で確認・増減できます。変更はすぐ保存され、次のプレイの周回数と周回に応じた展開に反映されます。

このリポジトリにはGodot 4.5.1で出力したWeb版のみを置いています。

2026年10月のR1第3次プレイテストを反映し、夜から翌朝への本文、蓮の探索文、集合写真・ナオのアルバム・卒業アルバム・TRUE ENDの写真裏を更新しました。R2第4タブの指摘を受け、END1の該当経路では母・美穂・主人公の三人で写真を撮る本文に改め、写真右端の身元不明者だけを余分な一人として描いています。

R3・F3のプレイテストと追加の視覚修正も反映済みです。身長線、連絡先を含む携帯画面、保護者欄を実写調素材に改め、最終質問の主人公写真は家族集合写真中央の本人と統一しました。
受信時の端末には差出人不明の新着メール通知を表示し、写真と回答を選ぶ画面は従来の自室背景と回答パネルの構図に戻しました。
